# UiPrimitives — Context

**Type**: React UI primitives
**Specialist**: frontend-dev

## Purpose
Generated/adapted primitives centralize styling variants for buttons, badges, drawers, sheets, forms, and inputs.

## Key dependencies
`@/lib/utils` — class merging; Radix/Base UI style packages — primitive behavior; Tailwind classes — styling.

## Patterns
Treat as shared infrastructure; avoid business logic in UI primitives.
