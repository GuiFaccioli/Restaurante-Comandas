# ElapsedTime — Context

**Type**: Utility module
**Specialist**: backend-dev
**Last updated**: 2026-07-03

## Purpose
Clamps future timestamps to 00:00; displays MM:SS below one hour and HH:MM:SS at one hour or more.

## Key dependencies
Plain TypeScript Date parsing.

## Patterns
Used by live timers in kitchen and waiter delivery queue.
